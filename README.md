# 🚀 Personal Portfolio Website

This is my personal **developer portfolio website** built to showcase my skills, projects, and contact information.  
The portfolio is fully responsive, modern, and user-friendly, designed to create a strong first impression.

---

## 🛠️ Tech Stack Used

- **React.js** – For building reusable and dynamic UI components
- **Tailwind CSS** – For fast, responsive, and clean UI design
- **EmailJS** – To handle contact form submissions without a backend
- **React Hot Toast** – For dynamic and user-friendly notifications
- **JavaScript (ES6+)**
- **HTML5 & CSS3**

---

## ✨ Key Features

- ⚡ Fully responsive design (Mobile, Tablet & Desktop)
- 🧩 Component-based architecture using React
- 🎨 Clean and modern UI with Tailwind CSS
- 📩 Contact form with EmailJS integration
- 🔔 Dynamic success & error notifications using React Hot Toast
- 🚀 Fast performance and smooth user experience

---

## 📬 Contact Form Functionality

The contact form is integrated using **EmailJS**, allowing users to send messages directly without any backend setup.  
Users receive instant feedback through **toast notifications** for successful or failed submissions.
